Vice Story — a GTA 6-style cover art maker. Turn your own photo and a caption into a multi-panel poster in the style of GTA 6's posters: three layouts (Sunset Split, Neon Grid, Vice Strip), four colour grades, three post sizes with exact-size PNG export, per-panel crop and zoom, editable chapter tags. Fully offline, photos never leave your machine. Original art only — no Rockstar logo, artwork or font.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
